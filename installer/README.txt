Spider-Verse Theme for ChatGPT / Codex Desktop
================================================

安装
----
1. 解压整个文件夹到任意位置。
2. 双击“安装.cmd”。
3. 如果 ChatGPT 正在运行，按提示输入 Y 重启一次。
4. 看到“安装完成”后，从桌面或开始菜单打开：
   ChatGPT · Spider-Verse

以后请使用这个主题快捷方式启动。右下角 SV THEME /
Alt + Shift + S 可以开关主题。

系统要求
--------
Windows 10/11 + ChatGPT / OpenAI Codex 桌面客户端。
不需要 Python、Node.js、浏览器扩展或管理员权限。

卸载
----
双击“卸载.cmd”。如果安装包已删除，手动删除：
%LOCALAPPDATA%\SpiderVerseCodexTheme
以及桌面/开始菜单/启动项里的 Spider-Verse 快捷方式。
